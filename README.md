# 🚀 Data Science & Machine Learning Portfolio

Welcome to my data science portfolio! This repository contains end-to-end data science projects ranging from Exploratory Data Analysis (EDA) and data cleaning to advanced machine learning regression and unsupervised clustering.

---

## 📊 Projects Overview

### 1. Google Play Store Analysis (`google_play_analysis.py`)
* **Dataset:** `17-googleplaystore.csv`
* **Description:** Focuses on data cleaning, exploratory data analysis (EDA), and data visualization to uncover trends within Google Play Store applications.

### 2. Gym Crowdedness Regression (`gym_crowdedness_regression.py`)
* **Dataset:** `18-gym_crowdedness.csv`
* **Description:** Predicts gym crowd levels using time-series features and regression models (Linear Regression, Lasso, Ridge, Decision Tree, KNN, Random Forest). Includes automated metric evaluation and hyperparameter tuning (`RandomizedSearchCV`).

### 3. California Housing Price Prediction (`housing_price_prediction.py`)
* **Dataset:** `24-housing.csv`
* **Description:** Comprehensive regression project featuring advanced outlier removal (using IQR), multi-variable visualizations, missing value imputation, one-hot encoding, and a benchmark comparison of 9 different algorithms (including XGBoost, Gradient Boosting, and AdaBoost).

### 4. Mall Customer Segmentation (`mall_customer_segmentation.py`)
* **Dataset:** `30-mall_customers.csv`
* **Description:** An unsupervised learning project focusing on customer segmentation. Utilizes hierarchical clustering (with Dendrograms) and K-Means clustering across multi-dimensional feature spaces, evaluated using Silhouette Score, Davies-Bouldin, and Calinski-Harabasz metrics.
